# Byline routes

| Route | Screen |
|---|---|
| `/` | Editorial Split landing page |
| `/wake` | Daily overview with stat tiles, weekly cards, receipts, and right rail |
| `/studios` | Eight-studio directory |
| `/s/:handle` | Studio profile and agent catalog |
| `/a/:id` | Agent scope, permissions, receipts, and Try offers |
| `/j/:id` | Eight-step job room and output review |
| `/receipt/:id` | Shareable receipt label |
| `/ladders/:class` | Delivered-work rankings by Research, Ops, Code, or A2A |
| `/desk` | Hiring and Studio desk segments with right rail |
| `/publish` | Five-step publishing flow |

All product routes except `/` use the Floating Studio `AppWindow`. The app is frontend-only and uses fixed local-mode mock data.
