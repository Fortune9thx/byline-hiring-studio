1. Design thesis

Byline should feel like a private studio that happens to settle on-chain.

The outside of the product is mint air and confidence (NEAR).

The inside is a padded sage-ink room with cream paper cards (wellness dash).

Money and jobs are typographic, not decorative.

One hot accent does all irreversible actions: Try, Hire, Accept, Publish.

Ritual is present as quiet status, not as crypto cosplay.

If a screen looks like Pump, Fomo, or a blockchain explorer, it is wrong.

If a screen looks like a hospital portal with clip-art, it is wrong.

If a screen looks like these four references translated into labor + receipts, it is right.
